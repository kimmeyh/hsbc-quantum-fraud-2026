## How Claude Code participates (practical guidance, not legal advice)

The T&C define Participants as legal persons: 18+, legal authority to enter the Terms, not sanctioned. An AI system cannot satisfy those requirements, so Claude Code cannot be a Participant or a legal team member. Nothing in the T&C or Guidelines restricts the use of AI tools.

Recommended structure:
1. Harold Kimmey is the sole Participant and team lead. He accepts the T&C and owns the IP.
2. The Team Profile discloses Claude Code transparently, either as a labeled row in the member table or a statement: "Development, experimentation, and drafting are AI-augmented using Anthropic's Claude Code as an engineering assistant, operating under the team lead's direction; all content is reviewed and approved by the team lead. Claude Code is a software tool, not a Participant."
3. Precedent: the SMU/OCBC CVQBoost paper acknowledges Copilot use; disclosure reads as professional, not as weakness. For this challenge, human-plus-AI workflow is arguably itself a quantum-AI-era credential.
4. Trademark: naming the tool ("Claude", "Claude Code") is honest nominative use. Do not use Anthropic logos or wording implying Anthropic sponsors or endorses the team.
